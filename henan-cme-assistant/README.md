# 河南医继续教育学习助手 · README

适用于 **Microsoft Edge**（Chromium 内核，Manifest V3）的浏览器扩展，为河南省继续医学教育学习平台
`https://yuancheng.henanyixue.com/` 提供**纯前端 DOM 监测辅助学习**：

- 检测视频播放状态（播放/暂停/结束/平台暂停/验证码弹窗等），事件监听 + 低频轮询兜底；
- 视频正常播放结束后，自动点击课程列表「下一节」，并校验页面**真实切换**后才确认成功；
- 滑动拼图打卡验证码弹窗出现时，**暂停自动切换**并做被动技术诊断，同时提供**标题闪烁 / 系统通知 / 浮窗提示**（可在面板关闭），等待**人工完成**验证，弹窗关闭后复核页面状态、安全恢复；
- 面板（popup）控制开关、查看状态与日志；课程页内提供可拖动的**浮窗控制面板**。

> ⚠️ 本扩展**不绕过任何后端校验**：验证码必须人工滑动完成；不做快进、不伪造进度、不伪造完成状态。
> ⚠️ 与油猴脚本共存：本扩展不劫持 `visibilitychange`、不改写 `HTMLMediaElement` 原型、不覆盖任何原生事件、不读取油猴内部变量；如与既有油猴脚本的切课逻辑同时开启，请在面板关闭「自动切换」避免双重触发。

## 一、功能清单

| 功能 | 说明 |
|---|---|
| 视频状态检测 | 10 种状态：无播放器 / 播放中 / 用户暂停 / 平台暂停 / 视频结束 / 切换中 / 验证码弹窗 / 等待人工验证 / 切换失败 / 课程全部完成 |
| 结束检测 | `ended` 事件为主，轮询兜底为辅（不单靠 currentTime）；同一课程**只触发一次**切课（按课程 key 去重 + 切换中互斥） |
| 用户暂停保护 | 用户手动暂停（点击播放器/键盘等）不自动切课、不自动恢复 |
| 失焦暂停识别 | 页面失去鼠标焦点（窗口 blur/被遮挡）导致的暂停归为「平台暂停」；焦点恢复 / 页面重新可见时做**一次**安全恢复（用户主动暂停不干预，5s 节流防双重触发） |
| 验证码暂停切换 | `.vertifyWrap` 弹窗出现 → 暂停自动切换 → 被动诊断 → 人工完成后复核恢复 |
| 验证码提醒 | 弹窗出现时：标签页标题闪烁 + 系统通知（各可独立开关，通知 30s 冷却防刷屏） |
| 页面浮窗 | 课程页内浮动控制面板（Shadow DOM 隔离样式）：状态/进度/验证码/日志 + 控制按钮，可拖动、可收起 |
| 自动切下一节 | 点击课程列表下一项；以「视频元素重建 / 播放源变化 / 课程标题变化」校验真实切换；失败有限重试（3 次）后停止 |
| 最后一节 | 无下一节入口 → 标记「课程全部完成」 |
| SPA 重发现 | MutationObserver 监听，播放器被重挂载（切课）时自动重新绑定 |
| 控制面板 | 中文开关 + 实时状态 + 日志 + 重新扫描 / 暂停恢复 / 清空日志 |
| 诊断模式 | 对验证码组件做结构/坐标/CSS/Canvas 像素/事件与状态迁移的**只读**诊断（详见《验证码组件技术诊断报告》） |

## 二、安装（Edge）

1. 打开 Edge，地址栏输入 `edge://extensions` 回车；
2. 打开左下角 **「开发人员模式」** 开关；
3. 点击 **「加载解压缩的扩展」**，选择本目录 `henan-cme-assistant`（包含 `manifest.json` 的文件夹）；
4. 安装后浏览器工具栏出现图标「豫」（蓝紫方块），固定到工具栏便于查看面板；
5. 打开 `https://yuancheng.henanyixue.com/` 登录并进入任意课程学习页，点击图标打开面板确认「运行中」。

> Chrome 也可安装：`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序。

## 三、使用方法

1. 进入课程学习页，视频开始播放后，面板应显示「播放中」与进度百分比；
2. 视频自然播放到**打卡时间点**时，平台会弹出「打卡」拼图验证码，同时面板状态变为「验证码弹窗 / 等待人工验证」，自动切换被挂起；
3. **人工拖动滑块完成拼图**（注意：验证码内置轨迹检查，直线快拖会提示「请再试一次」，请像正常拖动一样带上下轻微波动）；
4. 验证成功弹窗关闭后，扩展自动复核：若视频暂停则安全恢复播放；若正好结束则补做切课；
5. 视频播放结束且无验证码时，扩展自动点击课程列表下一项，校验「视频元素重建 / 播放源变化」后更新状态并继续监测；
6. 全部课程学习完（无下一项）→ 面板显示「课程全部完成」。

## 四、面板说明

- **开关**：自动切换下一节 / 视频结束检测 / 验证码暂停切换 / 诊断模式 / 标题闪烁提醒 / 系统通知提醒 / 页面浮窗面板；
- **状态区**：当前课程、播放器状态、播放进度（当前/总时长/百分比）、验证码状态、切课挂起；
- **按钮**：重新扫描页面 / 暂停自动化（不切课、不恢复播放）/ 恢复自动化 / 清空日志；
- **验证码诊断区**：最近一次验证码会话的状态迁移与观察统计；
- **日志区**：最近 120 条运行日志（含【已验证】/【观察】/【推测】标签）。

**页面浮窗**：进入课程页后右上角自动出现（可在面板关闭）。可拖动标题栏移动位置、点 ▁/▔ 收起展开；显示课程标题、播放器状态、进度、验证码状态与最近日志；按钮「重新扫描 / 暂停自动化 / 恢复自动化 / 清空日志」与 popup 等价。样式通过 Shadow DOM 隔离，不影响页面布局，也不读取/修改油猴脚本任何内容。

## 五、与油猴脚本共存建议

- 本扩展不会读取/写入油猴脚本任何变量，事件均通过 `addEventListener` 叠加（被动观察为主），不改原型、不 `preventDefault/stopPropagation` 页面事件；
- 若油猴脚本已有「自动切课」逻辑：在面板关闭 **自动切换下一节**，仅保留视频结束检测与验证码处理；
- 若油猴脚本已有「验证码弹窗处理」：在面板关闭 **验证码暂停切换**，避免重复挂起/恢复；
- 若油猴脚本已有「失焦/切后台自动恢复播放」：本扩展的安全恢复带 5s 节流，仍可能与油猴双触发——此时建议关闭本扩展的恢复行为（使用面板「暂停自动化」），或二选一保留一个恢复逻辑；
- 双脚本同时点击同一「下一节」可能跳过两节：切课前请核对面板「切课挂起」状态。

## 六、技术约束与合规

- Manifest V3：`content_scripts + service worker + MutationObserver`；
- 最小权限：`storage`（本地数据）+ `notifications`（验证码系统通知）；`host_permissions` 仅匹配 `https://yuancheng.henanyixue.com/*`；
- 数据仅存本地 `chrome.storage.local`（设置/日志/诊断/实时快照），**不上传账号、cookie、页面数据**；
- Content script 隔离环境运行，不篡改站点原生 JS；卸载扩展即完全移除。

## 八、常见问题

| 现象 | 处理 |
|---|---|
| 面板显示「内容脚本未响应」 | 安装扩展后需刷新一次课程页；或当前不在目标站点 |
| 视频结束没有自动切课 | 检查面板开关「自动切换」「视频结束检测」是否开启、是否为「已暂停」状态、日志中是否有「验证码弹窗/切换失败」记录 |
| 出现「切换失败」 | 手动点击课程列表下一项后点「重新扫描页面」；扩展不会无限点击 |
| 切后台视频被暂停 | 平台自身在标签页隐藏（含窗口失焦/被遮挡）时暂停（源码已验证），属平台行为；插件会在**焦点恢复/页面重新可见**时自动恢复播放一次，若不想自动恢复请用面板「暂停自动化」 |
| 验证码一直弹 | 打卡时间点由服务端下发，需逐次人工完成；可点弹窗右上角刷新按钮换图重试；弹窗出现时扩展会**标题闪烁 + 系统通知 + 浮窗标红**提醒，完成后自动恢复 |
| 不需要标题闪烁/系统通知/浮窗 | 在面板关闭对应开关即可；浮窗开关关闭后页面右上角面板隐藏 |
| 没收到系统通知 | 检查系统通知权限（Windows 设置 → 通知 → 允许 Edge/浏览器通知）；通知仅验证码弹窗时发送，30s 冷却 |
| 与油猴冲突 | 见「与油猴脚本共存建议」，或临时关闭对应开关 |
